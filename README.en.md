# iasi-standards

> Shared standards, templates and conventions for the IASI ecosystem.

`iasi-standards` is part of the **IASI (Engineering Assisted by Intelligent Systems)** ecosystem.

This repository does not contain software.

It contains the standards that define what an IASI project looks like.

---

# Why does it exist?

As the ecosystem grows, many resources stop belonging to a single project and become shared assets.

For example:

- Naming conventions.
- README templates.
- Licenses.
- `.gitignore` files.
- GitHub workflows and templates.
- Visual identity.
- Style guides.
- Project structures.
- Release processes.

Keeping these resources in a single place ensures consistency across every project in the ecosystem while avoiding duplication.

---

# Philosophy

Each project should solve its own problem.

Anything that is no longer specific to a single project and becomes useful to several projects should become part of `iasi-standards`.

This allows shared knowledge to evolve independently and be reused throughout the entire ecosystem.
