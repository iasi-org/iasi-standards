# iasi-standards

> Estándares, plantillas y convenciones compartidas del ecosistema IASI.

`iasi-standards` forma parte del ecosistema **IASI (Ingeniería Asistida por Sistemas Inteligentes)**.

Este repositorio no contiene software.

Contiene los estándares que definen cómo son los proyectos del ecosistema IASI.

---

# ¿Por qué existe?

A medida que el ecosistema crece, muchos elementos dejan de pertenecer a un proyecto concreto y pasan a ser patrimonio común.

Por ejemplo:

- Convenciones de nombres.
- Plantillas de README.
- Licencias.
- `.gitignore`.
- GitHub Actions.
- Plantillas de Issues y Pull Requests.
- Identidad visual.
- Guías de estilo.
- Estructuras de proyectos.
- Procesos de publicación.

Centralizar estos recursos garantiza coherencia entre todos los proyectos y evita duplicidades.

---

# Filosofía

Cada proyecto debe resolver su propio problema.

Todo aquello que deje de ser específico de un proyecto y pase a ser útil para varios debe incorporarse a `iasi-standards`.

De este modo, el conocimiento común evoluciona de forma independiente y puede reutilizarse en todo el ecosistema.
